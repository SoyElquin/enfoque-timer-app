# Pomodoro sin registro

## Respuesta rápida

Enfoque Timer está pensado para que puedas conocer la experiencia y comenzar una sesión sin que crear una cuenta sea el primer obstáculo.

[Abrir Enfoque Timer](https://enfoquetimer.vercel.app/)

## Empezar con menos fricción

Cuando una persona solo necesita concentrarse durante los próximos minutos, pedirle primero un formulario puede hacer que abandone. Por eso la propuesta de Enfoque Timer prioriza la acción: elegir una intención, iniciar el temporizador y comprobar si el flujo le resulta útil.

Puedes probar una sesión Pomodoro, explorar el modo libre y conocer la relación entre enfoque, descansos y progreso. La disponibilidad de sincronización, persistencia u otras funciones puede depender de la versión de la aplicación y de la configuración del usuario.

## Qué significa “sin registro”

Significa que el registro no debe ser la barrera inicial para probar el temporizador. No significa que todos los servicios futuros o todas las funciones avanzadas funcionen sin una cuenta. Si la aplicación solicita acceso para una función concreta, revisa qué se está habilitando antes de continuar.

## ¿Es para ti?

Este enfoque puede servirte si:

- Quieres probar un Pomodoro antes de comprometerte con otra herramienta.
- Necesitas iniciar una sesión puntual desde un navegador.
- Prefieres explorar primero y decidir después si deseas guardar más información.

## Preguntas frecuentes

### ¿Puedo probar el temporizador sin crear una cuenta?

La experiencia está diseñada para que puedas empezar sin hacer del registro el primer paso. La disponibilidad exacta puede cambiar según la versión.

### ¿Sin registro significa que no se guarda nada?

No necesariamente. La forma de guardar o sincronizar información depende de la experiencia y la configuración vigente.

### ¿Puedo usarlo para estudiar?

Sí. Puedes crear una intención concreta y comenzar una sesión desde el navegador.

### ¿Qué hago después de probarlo?

Si el flujo te sirve, explora [rutinas, misiones y progreso](../gamificado/) para construir una forma de trabajo más constante.
