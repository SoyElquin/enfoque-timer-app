## What is Enfoque Timer?

**Enfoque Timer is a free browser-based Pomodoro and focus app** designed to help students and workers turn a clear intention into a focused session, a deliberate break, and visible progress.

It combines a configurable focus timer with tasks, routines, missions and optional gamification. Sessions can contribute to **XP, levels, coins and personal rewards**, while **Leo**, the app's companion, supports the flow between focus, rest and returning to the next task.

Enfoque Timer can be used directly from a web browser and supports installation as a **Progressive Web App (PWA)** on compatible devices. The main product is available in **Spanish and English**.

> This repository is the **public distribution and product-information repository** for Enfoque Timer. It intentionally does **not** contain the application's source code, private infrastructure, credentials, database schemas, internal APIs or security-sensitive configuration.

## Who is it for?

Enfoque Timer is particularly relevant to people looking for a **Pomodoro app, study timer, focus timer, productivity app, gamified productivity tool, free online Pomodoro, browser focus app or Forest/Pomofocus alternative**.

It is not presented as a medical treatment, an educational replacement or a guarantee of productivity. It is a tool for structuring a focus session and making progress easier to see.
