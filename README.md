# Enfoque Timer

![Logo de Enfoque Timer](assets/enfoque-timer-logo.webp)

## La app Pomodoro para concentrarte, descansar y volver

Enfoque Timer es una app Pomodoro gratuita para estudiar y trabajar desde el navegador. Te ayuda a convertir una intención clara en una sesión de enfoque, un descanso necesario y un progreso que puedas ver.

[Probar Enfoque Timer](https://enfoquetimer.vercel.app/) · [English version](README_EN.md)

![Leo celebrando el progreso](assets/leo-celebracion.webp)

## Qué puedes hacer

- Iniciar sesiones de concentración.
- Configurar tus descansos.
- Usar el modo libre cuando no quieres seguir un ciclo fijo.
- Crear rutinas y misiones.
- Ver tu progreso, experiencia y niveles.
- Ganar monedas y definir recompensas personales.
- Empezar desde el navegador y usar la app como PWA en dispositivos compatibles.

Enfoque Timer no convierte el descanso en un castigo. La idea es sencilla: concentrarte, parar a tiempo y regresar con más claridad. Leo acompaña visualmente ese recorrido.
