## Product description

Enfoque Timer helps a person define a task, run a focused work or study block, take a deliberate break and return with visible progress. It supports Pomodoro-style sessions as well as configurable durations and a Free mode.

The product adds optional gamification through missions, XP, levels, coins and personal rewards. Leo is the product's visual companion.
