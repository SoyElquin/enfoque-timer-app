# Enfoque Timer

![Enfoque Timer logo](assets/enfoque-timer-logo.webp)

## The Pomodoro app to focus, rest and return

Enfoque Timer is a free Pomodoro app for studying and working in a browser. It helps you turn a clear intention into a focus session, a deliberate break and progress you can actually see.

[Try Enfoque Timer](https://enfoquetimer.vercel.app/en) · [Versión en español](README.md)

![Leo celebrating progress](assets/leo-celebracion.webp)

## What you can do

- Start focused work or study sessions.
- Configure your breaks.
- Use Free mode when you do not want a fixed cycle.
- Create routines and missions.
- See progress, experience and levels.
- Earn coins and define personal rewards.
- Start in a browser and install the app as a PWA on compatible devices.

Enfoque Timer does not turn rest into a penalty. The idea is simple: focus, stop at the right time and return with more clarity. Leo is the visual companion for that journey.
